# Tomate 🍅

Aplicação web para gerenciamento de tarefas com
temporizador Pomodoro.

🌐 [Acessar aplicação](...)

## Sobre

O Tomate é uma aplicação desenvolvida para combinar
gerenciamento de tarefas e técnica Pomodoro em uma
interface simples e responsiva.

## Funcionalidades

- Criação e exclusão de tarefas
- Organização por prazo
- Marcação de tarefas concluídas
- Temporizador Pomodoro
- Pausas curta e longa
- Persistência com LocalStorage
- Interface responsiva

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
